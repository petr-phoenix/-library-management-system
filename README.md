# Library Management System - Catalog Data Layer

Production-grade relational data layer for the Library Management System catalog, built with NestJS, Prisma ORM, and PostgreSQL.

---

## Getting Started

### 1. Prerequisites
- Node.js (>= 18.x)
- npm or pnpm
- A running PostgreSQL instance (local or hosted via Neon, Supabase, or AWS RDS)

### 2. Configure Environment
Navigate to the `api` workspace and clone the example environment file:
```bash
cd api
cp .env.example .env
